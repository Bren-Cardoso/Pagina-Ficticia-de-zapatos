# Página Web de Local de Zapatos

Proyecto de una página web de un local de zapatos desarrollado en 2024 para la materia Diseño de Interfaz.

## Descripción

El proyecto consiste en el desarrollo de un sitio web para un local de zapatos ficticio. La página permite presentar los productos del establecimiento y organizar diferentes categorías de productos de manera interactiva.

El objetivo fue aplicar los conocimientos adquiridos durante la materia en el desarrollo y diseño de una aplicación web.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Características

- Página principal del local.
- Menú organizado por categorías.
- Secciones para diferentes tipos de productos.
- Diseño de la interfaz utilizando HTML y CSS.
- Funcionalidades interactivas implementadas con JavaScript.

##Contexto académico

Proyecto realizado durante 2026 en el marco de la materia Desarrollo de Aplicaciones.
